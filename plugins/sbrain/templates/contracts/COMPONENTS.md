# Shared Component Catalog

> Read this in full (see `stack-frontend-vue` §1.1) before writing any new Vue
> component. This is not a pre-built library — it starts empty and grows as modules
> need shared primitives. A shared component that isn't listed here does not exist as
> far as the next module is concerned; a module-specific component does NOT belong
> here.
