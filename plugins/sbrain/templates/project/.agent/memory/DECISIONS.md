# Memory: Decisions

> Project decisions that are not large enough for an ADR but important to remember.
> The agent writes here when a non-obvious decision is made; the human when a direction
> is set. Never delete entries.

## Format

```
### Short title
**Date:** YYYY-MM-DD
**Context:** why the decision was needed
**Decision:** what was decided
**Alternatives rejected:** what else was considered
**Reversal cost:** low / medium / high
```
